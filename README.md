# Employee Management System

## Project Overview
The Employee Management System is a Python and MySQL-based project designed to manage employee records, calculate salaries, and analyze employee data through a menu-driven interface.

## Technologies Used
- Python
- MySQL
- MySQL Connector for Python
- SQL

## Features
- Add, search, display, update, and delete employee records
- Automatic salary calculation using HRA, DA, Medical, TA, and PF
- Employee statistics, including average, highest, and lowest salaries
- Department-wise salary analysis
- Salary distribution analysis
- Employee attendance management
- Attendance summaries and attendance percentage calculation
- Input validation for several fields

## Database Setup
1. Install Python and MySQL.
2. Install the MySQL Connector package:

   `pip install mysql-connector-python`

3. Create a MySQL database named `company`.
4. Create the required `employee` and `attendence` tables using the column structure in the project.
5. Update the database connection settings in the Python file.
6. Run the program:

   `python employee_management_system.py`

- Used SQL queries to perform CRUD operations
